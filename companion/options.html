Egodact Remote Companion

Verbind deze browser met de Remote-agent op je PC.

Verbinding

Standaard http://127.0.0.1:8787. Draait de agent op een andere PC, gebruik dan dat IP-adres.

De agent toont de token bij het starten en bewaart hem in Egodact_remote\data\token.txt.

Nog geen verbinding getest.
Starten
  1. Start de agent op je PC: start-remote.cmd of node agent/server.js.
  2. Open de link met token op je telefoon (http://<ip-van-pc>:8787/?t=...).
  3. Laat deze extensie ingeschakeld en dit tabblad gesloten; hij werkt op de achtergrond.
